# Image Assets

Place the following image files in this directory:

## Optional Files

The app uses programmatic rendering for most visual elements, but you can add these for enhanced visuals:

### Dice Images (Optional)
- `dice_1.png` - Dice face showing 1
- `dice_2.png` - Dice face showing 2
- `dice_3.png` - Dice face showing 3
- `dice_4.png` - Dice face showing 4
- `dice_5.png` - Dice face showing 5
- `dice_6.png` - Dice face showing 6

### Board Background (Optional)
- `board.png` - Custom board background image

## Format Recommendations

- **Format:** PNG (with transparency) or WebP
- **Resolution:**
  - Dice: 512x512 pixels
  - Board: 2048x2048 pixels
- **Color Space:** sRGB
- **Bit Depth:** 32-bit (RGBA)

## Design Guidelines

### Dice Images
- Clean, high-contrast dots
- Subtle 3D effect or flat design
- Consistent style across all faces
- White or light background
- Black or dark dots

### Board Background
- Color-coded quadrants (Red, Green, Yellow, Blue)
- Clear path markings
- Safe square indicators
- Star square highlights
- Center home area
- Transparent or semi-transparent for layering

## Sources for Assets

- Create custom using:
  - Adobe Illustrator
  - Figma
  - Inkscape (free)
  - Canva
- Use royalty-free resources:
  - [OpenGameArt.org](https://opengameart.org/)
  - [Kenney.nl](https://kenney.nl/)
  - [Itch.io Assets](https://itch.io/game-assets)

## Notes

- The app uses programmatic dice and board rendering by default
- Image assets will override programmatic rendering if present
- Ensure proper licensing for commercial use
- Keep file sizes reasonable for mobile performance
