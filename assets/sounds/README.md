# Sound Assets

Place the following sound files in this directory:

## Required Files

- `dice_roll.mp3` - Sound effect when dice are rolled
- `token_move.mp3` - Sound effect when token moves
- `kill.mp3` - Sound effect when a token is killed
- `win.mp3` - Sound effect when a player wins
- `button.mp3` - Sound effect for button clicks
- `background_music.mp3` - (Optional) Background music for gameplay

## Format Recommendations

- **Format:** MP3 or WAV
- **Sample Rate:** 44.1 kHz
- **Bit Rate:** 128 kbps (for MP3)
- **Duration:**
  - Sound effects: 0.5 - 2 seconds
  - Background music: 1 - 3 minutes (loopable)

## Sources for Free Sound Effects

- [Freesound.org](https://freesound.org/)
- [Zapsplat.com](https://www.zapsplat.com/)
- [Mixkit.co](https://mixkit.co/free-sound-effects/)
- [OpenGameArt.org](https://opengameart.org/)

## Notes

- The app will function without sound files (silent fail)
- For best experience, include all sound files
- Ensure proper licensing for commercial use
